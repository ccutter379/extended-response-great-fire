# Extended Response Writing — The Great Fire of Rome, AD 64

Four projector lessons for **Year 11 (NSW Stage 6)** that teach students to write an extended
response (analytical exposition), using one supplied case study so no prior knowledge is needed:

> To what extent was Nero responsible for the Great Fire of Rome in AD 64?

**Site:** https://ccutter379.github.io/extended-response-great-fire/

| Lesson | Page | Focus |
|---|---|---|
| 1 | `lesson-1.html` | Unpack the question — directive, key terms, scope; the evidence sort |
| 2 | `lesson-2.html` | Thesis and introduction — weighing the witnesses; the thesis ladder |
| 3 | `lesson-3.html` | Body paragraphs that analyse — PEAL; This Does That; embedding evidence |
| 4 | `lesson-4.html` | Conclude, write, check — conclusion; 25-minute timed write; self-assessment |

### Deck controls

`→` `␣` next step · `←` back · `N` teacher notes · `K` timer · `O` all slides · `T` light/dark ·
`L` legend · `1`–`7` toggle a colour · add `#7` to a lesson's address to open slide 7 fully revealed.

## Sources

Tacitus, *Annals* (trans. A.J. Church & W.J. Brodribb, 1876); Suetonius, *Nero* (trans. J.C. Rolfe,
1914); Cassius Dio, *Roman History* (trans. E. Cary, 1925). Modern historians' positions (A.A. Barrett,
*Rome Is Burning*, 2020; E. Champlin, *Nero*, 2003) are summarised, not quoted. Image: Hubert Robert,
*The Fire of Rome* (1785), public domain.
